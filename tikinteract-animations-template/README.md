# TikInteract Studio – Animații (template vizual)

Acesta este un prototype HTML/CSS/JavaScript, independent de proiectul TikInteract real.

## Deschidere
Deschide `index.html` în Chrome/Edge. Nu ai nevoie de Node.js sau de server.

## Ce poți testa
- Butonul **Animații** din meniul stâng
- Taburile Generator AI / Universuri / Biblioteca mea / Evenimente LIVE
- Schimbarea universurilor și a conceptului de previzualizare
- Durata (5/10/15 sec) și formatele (16:9 / 9:16)
- Încărcarea fotografiei local în browser (nu se trimite pe server)
- Animația demonstrativă a ilustrației

## Ce NU este conectat
- Generare video cinematică AI reală
- Supabase (Autentificare, Storage, tabele)
- API provider video
- OBS / TikFinity
- Credite AI

Grafica scenică inclusă este **artă conceptuală ilustrativă**, nu un video AI generat și nici o demonstrație de păstrare a identității persoanei.

Pentru integrarea în codul real, copiază structura/interacțiunile relevante în componentele proiectului existent și conectează backend-ul. Nu înlocui site-ul public cu această pagină standalone.
