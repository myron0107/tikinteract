Inter and Oxanium are served locally as variable WOFF2 fonts (weights 400–800).
Latin and Latin Extended subsets cover the Romanian characters used on the site.

Source: Google Fonts CSS API, downloaded 2026-10-18:
https://fonts.googleapis.com/css2?family=Inter:wght@400..800&family=Oxanium:wght@400..800&display=swap

Licenses are included in inter-OFL.txt and oxanium-OFL.txt.
The site does not request fonts from Google at runtime.
