# Home showcase artwork

These are optimized transparent versions of the original game characters,
used by the native canvas animation on Home. `manifest.json` records each
original asset and its dimensions; the original game files remain unchanged.

Cars are 1086×362. Motorcycle and horse sheets are 768×512. All files are
WebP with alpha, resized using Lanczos and encoded at quality 90. The original
wheel centers and horse frame baselines are scaled by the canvas renderer.

The background, road, lights and audience hearts are drawn directly in the
browser and require no bitmap backgrounds or video playback.
