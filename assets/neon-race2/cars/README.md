# Night coupe sprites

Created with the built-in image generation tool for Neon Interact. The original
generated PNGs retain transparency and are kept alongside optimized WebP runtime
assets. These sprites are exclusive to Neon Interact; the homepage illustration
and the original Neon Race keep their existing cars.

The red and blue coupes share a flat cel-illustrated style, dark lower panels,
smoky windows and illuminated wheel/sill accents. Blue was generated as a
matching colorway of the red coupe. Exact generation prompts are recorded in
`generation-prompts.json`.

`manifest.json` records alpha bounds and wheel centers used to place and animate
the cars. Cars occupy 460 track units, about 18% less than the previous 560.
